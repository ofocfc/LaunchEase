为什么选择 MacLaunch

回到熟悉的启动方式

以桌面壁纸为背景，保留程序坞空间，用贴近系统的动效和布局呈现所有应用。没有复杂的学习成本，打开就是启动台。

01

跟手、自然的翻页

页面会跟随触控板或鼠标滚轮移动，再根据手势速度和距离自然停靠。到达第一页或最后一页时，不会错误循环跳转。

  • Core Animation 原生渲染
  • 实时页面指示器
  • 支持触控板与鼠标滚轮
02

图标、文件夹和排序

拖动图标即可改变位置，其他图标会自动补位。把应用拖到另一个图标上可创建文件夹，也能随时将应用拖出。

  • 自由拖动与自动补位
  • 毛玻璃文件夹面板
  • 布局自动保存

按照你的 Mac 调整

添加任意应用文件夹，自定义行列数。图标尺寸与上下间距会根据屏幕、网格和程序坞大小自动适配。

  • 自定义扫描文件夹
  • 可调行数与列数
  • 自动避让程序坞

三步开始使用

1

下载并解压

下载最新版 MacLaunch.zip，然后双击解压。

2

拖入应用程序

将 MacLaunch.app 拖进 Mac 的“应用程序”文件夹。

3

首次打开

右键应用并选择“打开”，之后就能正常双击启动。
